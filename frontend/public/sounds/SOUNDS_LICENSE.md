# Gamification Sound Assets

Files in this directory:

* `xp_gain.wav` (~22 KB, 250 ms) — two-tone Duolingo-style "blip" played for any XP award.
* `level_up.wav` (~119 KB, 1348 ms) — ascending C-major arpeggio + sustained chord, played
  for level-up overlays.
* `streak_milestone.wav` (~99 KB, 1122 ms) — 4-note rising bell + high sparkle, played on
  3 / 7 / 30-day streak overlays.
* `badge_unlock.wav` (~69 KB, 780 ms) — quick glissando C6→E6 + bell-like G6/B6/D7 stack
  with long release. Played when a badge unlocks.
* `daily_champion.wav` (~120 KB, 1390 ms) — **gold fanfare** for the Daily Champion overlay
  (Phase 46/47). Brassy stacked-harmonic triplet herald (G4 → C5 → G5) — the classic
  V→I "ta-ta-TA!" — resolving into a sustained brassy C-major chord (C5 + E5 + G5 + C6
  with vibrato on top) with a long shimmering tail. Distinct from the level_up arpeggio
  (cleaner timbre, no rhythmic triplet) and the badge_unlock bell ding (no brass
  harmonics, no fanfare gesture). Generated by `make_daily_champion()` in the script.

## Why .wav and not .mp3?

Lossless PCM .wav is universally supported by `HTMLAudioElement` across every
major browser (Chrome, Safari, Firefox, Edge). Encoding to MP3 would require
shipping ffmpeg/sox into the build container; .wav side-steps that for files
this tiny (no real bandwidth difference at these sizes). If we later need
MP3 for hosting cost reasons, swap them in here and update `SOUND_SOURCES`
in `src/contexts/SoundContext.jsx`.
